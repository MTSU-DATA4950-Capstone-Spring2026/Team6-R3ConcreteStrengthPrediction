# Processed Data Folder

This folder stores cleaned, transformed, and modeling-ready datasets created from the raw concrete compressive strength data.

These files are generated by the project notebooks and are intended for reuse in later modeling and evaluation steps. Processed files should be reproducible from code in the repository rather than edited manually.

## Contents

### `team6_preprocessed.joblib`
Preprocessed train/test bundle created by `02_preprocessing.ipynb`.

This file contains:
- `X_train`
- `X_test`
- `y_train`
- `y_test`

Summary of preprocessing applied:
- Loaded raw concrete dataset
- Checked for missing target values and removed none
- Checked for duplicate rows and removed none
- Performed an 80/20 train-test split with `random_state=4950`
- Verified no missing predictor values in train or test sets
- Applied IQR-based outlier capping using **training data only**
- Saved the capped predictors and original target splits for downstream modeling

### `team6_feature_engineering_bundle.joblib`
Feature-engineering bundle created by `03_feature_engineering.ipynb`.

This file contains the final engineered feature sets used for modeling. Depending on the saved version, it may include:
- original train/test predictors
- engineered train/test predictors
- pruned engineered train/test predictors
- scaled engineered train/test predictors
- `y_train`
- `y_test`
- retained feature names
- dropped feature names
- fitted scaler object

Summary of feature engineering applied:
- Standardized column naming for consistency
- Built domain-informed engineered features from the original concrete mix variables
- Added grouped features such as:
  - totals
  - ratios/proportions
  - nonlinear transforms
  - age-based interaction terms
- Reviewed correlations with target strength
- Removed overly redundant engineered features where appropriate
- Prepared final retained feature sets for downstream model development
- Saved final engineered datasets for reuse in later notebooks

## Source Data

Processed files in this folder are derived from:

- Do not edit processed files manually.
- Regenerate them by running the corresponding notebooks.
- If multiple versions are created, use clear filenames and update the processing log below.
